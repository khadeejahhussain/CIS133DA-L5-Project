Generic Font Families

Generic font families group fonts by their appearance. Serif fonts have small strokes at the ends of letters, while sans-serif fonts do not. Monospace fonts give every character the same width. Cursive fonts resemble handwriting, while fantasy fonts have decorative designs.

CSS Color Methods

CSS colors can be specified using color names, hexadecimal codes, or RGB values. Color names use words such as blue. Hexadecimal codes begin with a hash symbol and use hexadecimal digits to represent red, green, and blue components, such as #0000FF. RGB notation specifies the amounts of red, green, and blue, such as rgb(0, 0, 255). These three examples all represent blue.
